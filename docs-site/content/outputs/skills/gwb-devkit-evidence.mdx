# 页面取证：`devkit.cdp`

`skill.read {"name":"gwb-devkit","file":"references/evidence.md"}` 读到的就是这一份。主文件是 skill「gwb-devkit」。

`devkit.cdp {"args":[<home 名>, <动作>, …]}` 在一个工作台页面里动手。动作与开关的全表在包内
`bin/cdp.mjs` 的文件头，那份是唯一的真相：

- 浏览器输入：`move` / `click` / `rclick` / `drag` / `type` / `key` / `scroll` / `shot`
- 工作台契约：`cmd <命令名> [JSON]` / `reload [选择器]` / `home` / `eval <文件> [JSON]`

```
devkit.cdp {"args":["<home 名>","eval","D:\\…\\out\\量一下.js"]}
devkit.cdp {"args":["<home 名>","shot"]}
devkit.cdp {"args":["<home 名>","cmd","plugin-manager.list"]}
devkit.cdp {"args":["<home 名>","home"]}
devkit.cdp {"args":["<home 名>","click",".dv-tab@=日志"]}
```

**第一个位置只收 home 名**。端口从那个 home 的 `runtime.json` 查、验活，连上后拿页面自报的 home
名核对一次；记录坏了的 home 停掉重开一次就够得着了。

**`cmd` 只打隔离 home**：它经页面上的 `window.gwb.command` 调那个 home 的整张命令面，发的是真操作。
隔离 home 的底座里没有 MCP 门，这条就是它的日常入口。

## `eval`

- 文件里是**一个函数表达式** `(args) => 一张表`，想 await 就写 async；第二个参数是一段 JSON，
  不给按空对象调。返回值就是读数
- **文件只收绝对路径**，相对的当场拒：`devkit.cdp` 不看工作目录（走总线时那是 devkit 包自己的目录）。
  PowerShell 里 `(Resolve-Path <文件>).Path` 拿绝对路径
- 表达式放文件：命令行上 PowerShell 的引号会截断它
- 一次性的量表脚本落你自己仓的 `out/`（gitignore）；提交进仓的会跟着界面一起变黄，而且不报错

## `shot`

- 缺省落**被截的那个 home 自己的目录** `<home>\out\cdp\shot-<时刻>.png`，回执 `file` 是绝对路径。
  它是那个现场的证据，`devkit.home.rm` 删 home 时跟着没
- 要落别处：`shot <绝对路径.png> [选择器]`，相对路径当场拒
- 落点在 devkit 包目录或任何 `node_modules` 里也拒——那是装好的包，写进去弄脏它

## 两条实机规矩

- **先点标签再取证**：dockview 只渲染激活的那个窗格，取证前 `click` 它的 `.dv-tab`。
  用 `click` 发真事件——页面里自己造的事件不做命中测试，被浮层盖住的目标照样点得中，
  而这套界面最常出的错正是遮挡
- **量颜色先关过渡**：注一条 `transition: none` 再读；读到 `oklab(…)` 就是还在过渡中。窗口最小化时
  Chromium 节流后台动画，等多久都可能读到起点值

## 工作台没起的时候

CLI 本体零依赖，能直接跑：

```powershell
node <devkit 包根>\bin\cdp.mjs <home 名> <动作> [参数…]
```

内核要带 `--remote-debugging-port=<端口>` 与 `--disable-backgrounding-occluded-windows` 起才够得着；
`devkit.home.new` / `open` 起的自动带上。后一个开关管的是：窗口被整个盖住时 Chromium 停止产帧，
截图拿到陈旧帧。
