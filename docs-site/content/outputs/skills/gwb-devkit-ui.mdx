# 插件界面：读 `gwb-shell`

开发或修改插件界面，读外壳自己带的说明书：

```text
skill.read {"name":"gwb-shell"}
```

窗格、shadcn 官方组件配置、配套 tokens、样式前缀、多桌面浮层与界面验收都在那一份里。建仓、隔离 home 与发版读说明书 `gwb-devkit`。

`skill.read` 报找不到 `gwb-shell`：用 `plugin-manager.list` 看这个 home 的外壳与说明书插件是否 `active`，外壳是否已升级到带这份说明书的版本。
