# UI 接入说明书入口

**本页回答**：从 devkit 的旧 UI 附件入口到哪里读取当前接入规则。

开发或修改插件界面，读取 shell 自己携带的说明书：

```text
skill.read {"name":"gwb-shell"}
```

窗格、shadcn 官方组件配置、配套 tokens、样式前缀、多桌面浮层与 UI 验收，都由这一份维护。
devkit 只负责脚手架、构建、测试 home 和发版，不复制或代挂 shell 的说明书。

若找不到 `gwb-shell`，检查当前 home 是否启用了 shell 与 skills，以及 shell 是否已升级到携带该说明书的版本。
这份旧附件保留作指路，不能替代当前 shell 的接入规则。
