# 那支 CDP 驱动

**本页回答**：`bin/cdp.mjs` 管到哪儿为止、它凭什么是一支零依赖的纯 JS 单文件、以及它跟本包别的
代码为什么不共用任何东西。

## 管什么

把「一个选择器」翻成「视口里的一个点」，检查那个点上最上面的确实是它，然后让浏览器把事件派下去；
外加几条不看界面的动作。十二个动词分两类，来源不同：

| 类 | 动词 | 它依赖的是 |
| --- | --- | --- |
| 浏览器输入 | `move` / `click` / `rclick` / `drag` / `type` / `key` / `scroll` / `shot` | Chromium 的 Input 与 Page 域 |
| 不看界面 | `eval` / `cmd` / `reload` / `home` | Runtime 域；`cmd` 还要页面上有 `window.gwb.command`，`home` 还要地址里带 home 路径 |

**点不着的时候会告状**，这是它比「在页面里自己造事件」强的地方：造出来的事件不做命中测试，目标
被浮层盖住照样打得中，而遮挡正是界面最容易出的错；造出来的事件 `isTrusted` 是假的，按可信输入
设防的地方行为两样。这儿发的是浏览器层的事件，命中测试是浏览器自己做的，打不中时它把挡路的那条
祖先链和目标的 `pointer-events` 一起报出来。

{/* ref file="../bin/cdp.mjs" lines="298-311" */}

**问一张页它是哪个 home**，靠的是页面上那些 `file://` 地址里带着的 home 路径（外壳注的样式表与
importmap 都是）。不用配置、不用猜；出现不止一个 home 就说不猜，不挑一个。

{/* ref file="../bin/cdp.mjs" lines="408-437" */}

这一问不只是 `home` 那个动词的正身，**每一趟都要问一次**：连上之后先拿它跟你给的名字对，不符就停。

{/* ref file="../bin/cdp.mjs" lines="669-686" */}

记录只说「它起的时候用的是这个端口」，不说「此刻这个端口上还是它」。进程可能已经退了、端口被下一个
进程占走，而记录还躺在那儿指着那个数。名字是唯一的地址之后，这道核对就是「地址对不对」的最后一关；
少了它，名字给的是一种假的安全感。

所以 `home` 这个动词回的**不是「对不对得上」**——那件事在 `run()` 之前已经做完了——而是那个 home
的绝对路径。`devkit.dev` 拿它当守卫，挡住 `default` 与本插件自己住的那个 home。

## 不知道什么

**不知道页面里有什么。** 量什么是跟着界面走的，界面改一版就要添一段、改一段；而这支脚本管的是怎么
把事件发进页面，那件事一年也不该变一次。混在一起，稳的那半会跟着不稳的那半一起动。所以要量一张表
就写一个文件，`eval <文件> [JSON 参数]` 把它送进去跑。

{/* ref file="../bin/cdp.mjs" lines="381-406" */}

**文件里一律是一个函数表达式**，`(args) => 一张表`，想 await 就写成 async；不给参数就按空对象调。
只有这一条规则——「是函数就调、不是就直接求值」是两条规则伪装成一条，而选错分支的那次不报错，只是
回一个看不懂的值。文件落哪儿是调用方的纪律，一次性的落 `out/`（那儿 gitignore 着，本来就随时可以
清空）；提交进仓的那种会跟着界面一起变黄，而且不报错。

**不知道自己装在哪。** 截图落点与 `eval` 那个文件的相对路径都按**工作目录**算，不按这个文件在哪算。
它住在 home 的 `node_modules` 里，照文件位置解，解出来的是别人依赖树里的路径。

**不知道本包别的代码存在。** 它不 import 任何东西，连 `src/` 都不看一眼。收 home 名那一格也一样：
它自己拼出 `runtime.json` 的路径去读，不借 `src/home.ts` 里那套解析。

**不查 pid，也不问端口归谁。** 它只把端口读出来就去连，连不上就照实说连不上：

{/* ref file="../bin/cdp.mjs" lines="151-165" */}

裸的 `ECONNREFUSED` 会把人引去查网络，而这种情况压倒性的原因是那个 home 已经
退了、记录还留着（记录进程退了不删，那是故意的）。**真正的验活在上游**：`devkit.dev` 那条链动手
之前核对 pid 与端口持有者，那三道在测试 home 那一页。这儿只负责「连上的这张页到底是不是它」。

## 数据结构

没有持久结构。一趟就是：连上唯一那个页面，发几条 CDP 消息，把结果打成一张 JSON 到标准输出。
失败时那张 JSON 照样打全，只把退出码置成非零。

## 提供的接口

两条到达路径，同一个身体：

- 工作台跑着的时候走总线，`devkit.cdp {"args":["<home 名>","<动作>",…]}`，经 `gwbNodeCli`
  登记，回执自带 stdout 与退出码
- 工作台没起的时候直接 `node <包根>/bin/cdp.mjs <home 名> <动作>`

{/* ref file="../src/index.ts" lines="429-436" */}

**第一个位置只收 home 名**，端口从 `<home 根>/<名>/runtime.json` 里查出来。给数字当场拒，不静默
改道：

{/* ref file="../bin/cdp.mjs" lines="90-121" */}

**端口不是地址。** 它是一个没有语义的数，敲错一位就落在另一个现场，而那个现场会老老实实收下你
发的事件，事后也看不出哪儿不对。名字有拼写、有记录、连上之后还能跟页面自报的名字对一次，三样
端口都没有。代价是这支驱动从此**只驱动得了 gwb 的窗口**：别的 Chromium 页没有那份记录，也答不出
自己属于哪个 home。

**home 根只在拿得准的平台上认**（Windows 是 `%APPDATA%\gwb-kernel\homes`），拿不准就照实说，不猜。
记录不在、或者记录里没有 `cdp` 那一格（起的时候没带那个开关），都是「够不着」：照实报，让人停掉
重开一次。

**挑不出唯一一张页时，候选整张表就在错话里**：零命中报「现有这些」，多命中报「用 `--target` 挑
一个」，两句都带着那几张页的标题与地址。所以不必先另跑一条命令去列页——那条命令回的东西，正好是
出错时本来就会打出来的那份。

{/* ref file="../bin/cdp.mjs" lines="169-178" */}

**这是它必须是零依赖单文件、必须是纯 JS 的全部理由。** 第二条路径是它存在的一半：工作台起不来
的时候，人还得有办法问那扇窗到底怎么了。要它进 typecheck，就得让它变成要先构建的东西，而要先
构建的东西在「工作台起不来」那个时刻正好用不上。代价是它那十二个动词没有类型守着。

## 依赖的接口

三样：Node 的 `fetch` 与 `WebSocket`（连 Chromium 的调试端口）、目标页上的 `window.gwb.command`
（只有 `cmd` 那个动词用），以及 home 里那份 `runtime.json`（每趟读一次，只读 `cdp` 那一格）。
三样都不是本包的代码。

**看门狗按动词分档，不是一个数。** 它防的是页面卡住，不是「这条命令干的活久」：工作台的一条命令
可能在装依赖、在构建，十几秒回不来是常态，按十五秒掐掉的话，掐的是一条正在干活的命令，而那头
不会因此停下，回执从此没人接。输入与求值那几档还是十五秒，它们要么立刻回，要么就是页面真卡住了。

{/* ref file="../bin/cdp.mjs" lines="139-145" */}

五个开关：`--target` 页面不止一个时按标题或地址挑、`--mod` 带修饰键、`--pad` 给 `shot` 的裁剪留边、
`--size` 把视口当成这么大（会话级，必须跟动作同一句）、`--timeout` 改那条看门狗。

## 怎么单独测

**它没有单测，只有实跑。** 它做的每一件事都要一个真的 Chromium 调试端口在那头：发真事件、量命中、
截真图。喂假实现测得到的只剩参数拼接，而那不是它出错的地方。

它的验收方式是被用：`devkit.dev` 那条链的重挂、刷新、取证三步就是起它的子进程做的，链绿就说明这
几个动词是通的。要单独看一眼，起一个隔离 home，`node bin/cdp.mjs <home 名> home` 是最小的一跑：
它回得来，就说明查端口、连页、核对身份三件事全通了——那一步不通它压根不往下走。

**只对隔离 home 用，绝不打 default。** 这儿发的是真操作，会真往库里写。

## 代码地图

**在哪**：`bin/cdp.mjs`，一个文件，文件头就是完整的动词表与开关表。

**先读**文件头那三十行，动作怎么写、点怎么写、内核要带哪两个开关全在那儿。

**读序**：`portOf`（home 名怎么变成一个端口）→ `connect`（连上唯一那个页面，零命中与多命中都把候选
打进错话）→ `assertHome`（连上的这张页是不是它）→ `probeExpr`（选择器怎么收敛成一个点）→ `run`
那个 switch（一个动词一格）。

**可跳过**：按键虚拟码表与鼠标事件的参数拼装，那是 CDP 的形状，不是这支脚本的判断。

**内核要这样起**，两个开关缺一不可：`--remote-debugging-port=<端口>` 开出调试入口，
`--disable-backgrounding-occluded-windows` 关掉遮挡节流。少了后一个，窗口被别的窗口整个盖住时
Chromium 判定它不可见、停止产帧，截图拿到陈旧帧、`requestAnimationFrame` 一次都不回。
