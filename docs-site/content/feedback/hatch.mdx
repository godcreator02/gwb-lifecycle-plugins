# 孵化

**本页回答**：这个仓里有哪些手工操作已经重复过，值不值得做成一条命令、一份说明书或一个脚本。

## 这一页是干什么的

同一件手工操作**短期内碰到第三次**，或者人点名说「这个该做成工具」，就在这儿记一条。
记的时候不判断该做成什么形态，只把现场记下来：做了什么、为什么又手工做了一遍、当时手边
缺的是什么。形态等攒够了再判，判早了多半判错。

升格之后这条就该走：做成了命令或 skill，把条目删掉，**决定落一张[轨迹卡](/trajectory)**，
那儿才是它的档案。半年没人再碰的条目也直接删。这一区是周转区，不是档案馆。

**跨仓的反馈不落这一页，也不落这个站。** 在别的仓干活时发现这个件不好用，那条话投到总控台
那个固定路径的收件箱里，追加一段、标清是关于哪个仓。收件箱只有一个，落在各仓的站里就等于
没人看。反馈区因此只有孵化这一页，装的全是本仓自己的重复操作。

## 格式

一条一节，新的在下：

```text
## <yyyy-MM-dd> <一句话标题>

重复了几次、各在什么场合。当时手工做的是什么，缺的那个口长什么样。
```

## 条目

此刻一条都没有。
