# 还没做的三件事

**本页回答**：全生态机制定案（原交接页 `spec/ecosystem-simplify`，已删，内容在 git 历史里）收尾时，和本仓相关、还没做的有哪几件，各在等什么。下游插件仓的迁移项不在这里跟踪。

## 源上约五百个旧开发版删不删

devkit 0.20.0 之前，`devkit.dev` 把开发版发到团队源、打 `dev` 标签，源上因此留着约五百个 `-dev.*` 版本。它们不动 `latest`，不影响装包。

**人暂定不删**：删除不可逆，要人同意；不删也不影响别的事。要删的话先定留哪些（比如还被哪个 home 的清单引用着的）。

## `devkit.home.new` 改为经插件管理装基础插件

`devkit.home.new` 现在在新 home 启动之前自己写 `cordis.yml`、直接运行三次 `pnpm add`：那时插件管理还没装、home 还没启动，没有可调的插件管理。这是「只由插件管理写 home」唯一的例外。

候选做法：只直接装内核包、`cordis` 与插件管理，启动之后其余基础插件经 `plugin-manager.install` 装。代价是开 home 要多等一次启动、多一段经 CDP 调命令的流程。没定。

## 清理 default 里的库

default 的清单里除了插件、内核包与 `cordis`，还有接口类型包 `@godcreator/gwb-plugin-api`（0.4.1）。它是库，运行时用不到，home 里只该有插件。

清掉要在 default 上运行 `pnpm remove`，经插件管理做；先确认没有插件还在 peer 里写它、按值 import 它。default 里还有 agent-hooks-skills、docs-site、dsh、unit-folder 四个插件的 peer 写着它（`plugin-manager.list` 的 `unmetPeers` 报出来的），这几个插件改造完再清。
