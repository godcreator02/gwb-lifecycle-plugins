## 现场

建仓模板 `plugins/devkit/template/repo/pnpm-workspace.yaml.tpl` 的注释写着：文档站自带 `pnpm-workspace.yaml`、自己一套依赖、
自己 install，「收进来就成了 workspace 里嵌套 workspace，pnpm 不支持这种结构」，所以 `packages` 只有 `plugins/*`。

本仓仓根的 `pnpm-workspace.yaml` 却写着：

```yaml
packages:
  - plugins/*
  # 文档站：自己的依赖树，不进根 check
  - docs-site
```

照模板迁的仓（gwb-docs-site，2026-09-26）没收文档站；god-live-doc 收了，但那是有意的例外：它的站用 `workspace:*`
引本仓的 npm 包，写在它自己的轨迹卡里。

## 期望

二选一写定：要么本仓照模板把 `docs-site` 移出 workspace；要么模板注释改成「看情况」，并写清楚什么时候该收。
现在照着参照仓和照着模板会得出两种布局。
