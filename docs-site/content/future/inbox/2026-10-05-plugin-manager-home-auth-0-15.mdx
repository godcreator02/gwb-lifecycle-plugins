title: 跟进 plugin-manager 0.15 的当前 home 包源鉴权
description: 来源：plugin-manager，2026-10-05 凭据整体适配
---

`@godcreator/gwb-plugin-manager` 0.15 把包源认证改为当前 home 的共享 `npm-auth` 凭据，不再继承机器、其他 home 或工程中的认证。工程和工作区 `.npmrc` 的认证必须先按 skill 迁移，普通 registry 路由继续保留。

本仓 devkit 应通过新增 `withHomeRegistryAuth` 导出，为依赖安装、发布、组件安装及创建隔离 home 所需的包安装提供发起 home 的鉴权。创建新 home 不复制凭据。devkit 同时按旧机器认证语义变化发布 0.26；已扫描容器内 package.json，除自身外没有直接 peer/dev 下游。UI 的 plugin-manager 下游通知已在 UI 仓独立提交。

完成隔离 home 和真实 pnpm 验证、配齐 default 的 npm-auth 后，再整体升级 default。
